BM Movies — Documentação Inicial

Objetivo Geral

Desenvolver uma aplicação web full stack para recomendação, classificação e organização de filmes, permitindo que usuários salvem favoritos, realizem avaliações e organizem filmes assistidos.

---

Regras de Negócio

Usuários

- O usuário deve conseguir criar conta;
- O usuário deve conseguir realizar login;
- O sistema deve manter a sessão ativa.

Filmes

- O sistema deve listar filmes populares;
- O sistema deve permitir avaliações;
- O sistema deve permitir favoritar filmes.

Favoritos

- O usuário poderá salvar filmes;
- O usuário poderá remover favoritos.

---

Tecnologias

Front-end
- Vue.js
- Vite

Back-end
- Node.js
- Express.js

Banco
- Supabase PostgreSQL

---

Funcionalidades

- Login
- Catálogo de filmes
- Favoritos
- Perfil do usuário
- Diário cinematográfico

---

Estrutura do Sistema

Front-end
- Interface Vue.js

Back-end
- API REST

Banco de Dados
- PostgreSQL via Supabase
